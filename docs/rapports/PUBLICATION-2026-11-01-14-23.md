## Règles appliquées

- `supabase db push --dry-run` **puis** `supabase db push` : jamais l'inverse.
- Aucune commande destructrice (`db reset`, `db pull`, `db diff`, `db dump`) n'est employée.
- Les migrations restent immuables : une correction passe par un nouveau fichier `00xx_*.sql`.
- Aucun secret n'est écrit dans le dépôt ni dans ce rapport.
- Publication par connexion directe (`--db-url`) : aucun jeton d'administration n'a été requis ni demandé.
- La chaîne de connexion, qui contient le mot de passe de la base, est masquée dans ce rapport.
