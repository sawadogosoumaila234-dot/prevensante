# État réel du projet — contrôle du 12/11/2026

> Ce document prolonge `ETAT-2026-11-11.md`. Il répond à une question précise : **peut-on nommer
> les cinq personnes du site pilote sans transmettre la chaîne de connexion de l'instance ?**
> Réponse : **oui, et c'est fait de deux façons.**

---

## 1. Le verdict

**La chaîne de connexion n'est plus à transmettre.** Elle est **déjà sur la machine**, dans un
fichier local jamais versionné et jamais envoyé sur le serveur. Les outils la retrouvent
eux-mêmes.

Et même si ce fichier disparaissait, les cinq noms s'écrivent **sans aucun secret de base** :
par l'API de l'application, avec le seul compte administrateur.

## 3. Ce qui a été trouvé cassé, et corrigé

| # | Constat | Gravité | Correction |
|---|---|---|---|
| 1 | **La question de la chaîne de connexion n'avait pas lieu d'être posée.** La chaîne est dans `supabase/.env.local`, sur la machine, depuis la création du projet. | Moyenne — une valeur demandée à l'utilisateur pour rien | `tools/chain-connexion.mjs` : recherche centralisée (environnement → `.env.sauvegarde.local` → `supabase/.env.local` → ligne de commande) |
| 2 | **L'écriture des noms échouait sur le TLS.** La chaîne contient `?sslmode=require`, que les versions récentes de `pg` traitent comme un alias de `verify-full` : la connexion échouait sur « self-signed certificate in certificate chain », **malgré** `ssl: { rejectUnauthorized: false }`. | Moyenne — l'outil de nommage ne pouvait écrire du tout | le paramètre est retiré de la chaîne transmise à `pg`, qui applique alors sa propre règle (TLS, sans vérification stricte) |
| 3 | **L'export hebdomadaire hors site n'a jamais tourné.** Deux causes cumulées : le secret `SUPABASE_DB_URL` n'était pas dans le dépôt, et le chemin de l'artefact (`~/.prevensante-sauvegardes`) ne correspondait pas au dossier produit (`~/prevensante-sauvegardes`) — l'artefact partait donc vide. | **Élevée** — une décision d'exploitation validée (A10) reposait sur une copie qui n'existait pas | chemin d'artefact corrigé, `if-no-files-found: error` ; la CLI est maintenant lancée sans passer par un `.cmd` (`spawn EINVAL` sous Windows) ; `--schema-only` est produit par filtrage vérifié du dump complet |
| 4 | **L'export local exige Docker** (la CLI lance `pg_dump` dans un conteneur), absent de ce poste — et les règles du projet interdisent de démarrer un conteneur. | Moyenne | message explicite, et l'export hebdomadaire se fait par le workflow GitHub, où Docker est présent |

## 4. Ce qui reste — et ce n'est pas de l'ingénierie

| # | Point | Qui | Nature |
|---|---|---|---|
| 1 | **Nommer les personnes** qui tiendront les rôles du site pilote (HSE, médecin du travail, administrateur, directeur de site, superviseur) | Commanditaire | métier |

> La chaîne de connexion ne figure plus dans cette liste : **rien ne doit être transmis**.
> Le nom s'écrit dans l'application, et l'application affiche le nom — le reste ne change pas.

Reste une seule question d'exploitation, qui ne concerne pas l'application : l'export
hebdomadaire hors site a besoin d'un accès à la base **depuis les runners GitHub**. Ce secret
est aujourd'hui absent du dépôt ; il peut y être posé (chiffré, comme les 8 autres secrets
déjà présents), ou rester absent — la sauvegarde quotidienne automatique de la plateforme
continue, elle, de fonctionner.

## 5. Comment rejouer ce contrôle

```bash
npm run habilitations:maj -- --simulation   # voie SQL, lecture seule
npm run habilitations:maj:api -- --simulation  # voie API, sans chaîne, lecture seule
npm run habilitations:preuve                # preuve réversible : écrit, relit, restaure
npm run base:verifier                       # instance réelle : 15 contrôles RLS
npm run mfa:enroller -- --verifier          # preuve aal2 sur les 5 rôles
npm test                                    # 34 tests du routeur
```

## 6. Le point à retenir

Une question posée à l'utilisateur — « pouvez-vous recopier cette ligne ? » — a été traitée
comme une tâche technique, alors que la réponse était déjà sur la machine. La règle qui en
découle : **avant de demander une valeur à un humain, chercher si l'outillage ne peut pas la
trouver ou s'en passer.** C'est ce qui a été fait ici, et c'est ce qui rend le geste restant
unique : cinq noms.
